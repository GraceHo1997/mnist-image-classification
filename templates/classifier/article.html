01 · Objective

Classifying handwritten digits reliably

The objective is to train a convolutional neural network that exceeds 99% validation accuracy on MNIST, then make its predictions accessible through an authenticated web application.

Success criteria

Exceed 99% validation accuracy, select the final architecture using validation performance, retrain it on all 60,000 training images, and evaluate it once on the untouched 10,000-image test set.

02 · Dataset and preprocessing

Consistent inputs for training and inference

MNIST contains grayscale images of handwritten digits. The Django application accepts a headerless 28 × 28 CSV with pixel values on either a 0–1 or 0–255 scale. Values are converted to float32; inputs above 1 are divided by 255, then reshaped to (1, 28, 28, 1) before inference.

03 · Validation approach

Selecting the model before test evaluation

Architecture selection was based on validation performance. The test set was kept separate from model selection and was used only after the final architecture and training settings had been fixed.

04 · Experiments

Three candidate models compared

In the finalized recorded validation run, Model 2 achieved the highest validation accuracy and was selected as the final architecture. Model 2 and Model 3 were separated by only 0.0333 percentage points, so the selection reflects the finalized run rather than a claim that Model 2 will outperform Model 3 in every retraining.

05 · Final architecture

Model 2 selected for deployment

After model selection, the Model 2 architecture was rebuilt with fresh weights and trained on all 60,000 MNIST training images for 18 epochs. The resulting model was saved as mnist_classifier_group5.keras and integrated into the Django backend.

08 · Limitations and interpretation

Performance is high, but model ranking is run-specific

The finalized validation run placed Model 2 slightly ahead of Model 3. Because the difference was only 0.0333 percentage points, the comparison should be interpreted as the result of the finalized experiment rather than evidence that Model 2 is universally superior across every retraining run.

More broadly, handwritten digits can be visually ambiguous, and 28 × 28 images may lose subtle stroke details. Future work could evaluate repeated training runs, targeted augmentation, calibration, or model ensembles.
